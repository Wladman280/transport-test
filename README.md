# Тестирование — 8 категорий

## Что изменено
- На главной странице отображаются 8 категорий вертикальным списком.
- Категории 1, 4, 5 и 7 сохраняют имеющиеся вопросы.
- Категории 2, 3, 6 и 8 созданы как пустые разделы для будущего наполнения.
- Панель администратора позволяет выдавать ключи для любой комбинации из 8 категорий.
- Убрана полоса-индикатор проверки ответов.
- После правильного ответа фон страницы становится зелёным, после неправильного — красным.
- Поле срока действия не предлагает прошедшие даты; проверка срока дополнительно выполняется самой базой данных Supabase.
- На входе больше нет текста с названием Supabase/базы данных.

## Обновление Supabase
Открой SQL Editor и выполни `supabase-setup.sql`. Скрипт обновляет ограничение категорий и устанавливает триггер, запрещающий сохранять ключи с уже истёкшим сроком. Действующие записи не удаляются.

## Публикация GitHub Pages
Загрузи `index.html` в корень репозитория (замени старый файл). Если `supabase-setup.sql` уже выполнялся раньше, повторно выполни обновлённый скрипт в SQL Editor. В GitHub открой Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Публичный Supabase Publishable key используется в HTML. Никогда не добавляй `sb_secret_` или `service_role` ключ в HTML или GitHub.
